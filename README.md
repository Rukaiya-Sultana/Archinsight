# \# ArchInsight

# 

# \### AI-Powered Software Architecture \& Dependency Intelligence Platform

# 

# ArchInsight is an AI-powered web application designed to help developers understand and manage complex software projects. The platform analyzes GitHub repositories using Abstract Syntax Tree (AST) parsing, identifies relationships between files, modules, classes, and functions, and automatically generates interactive software architecture diagrams. By integrating Large Language Models (LLMs) with Graph Retrieval-Augmented Generation (Graph RAG), the system allows developers to explore unfamiliar codebases, ask architecture-related questions, and understand how different components interact.
